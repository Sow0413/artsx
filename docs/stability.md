# 安定

対象は iPhone と iPad だけ。Android 版は作らない。快測ナビが落ちるのは、端末の外で状態を持っているからでもある。ここは、観測も座標簿も、その端末の中だけで確定する。

## すぐ書く

点を残したとき、基準点の計測が始まったとき、画面を移したとき、その場で SQLite にコミットする。ファイルは現場の `現場.sqlite`。モードは WAL。座標簿の `book.sqlite` も WAL。通信の返事は待たない。

コミットが戻った行は、クラッシュや強制終了のあとも残る。コミットする前に落ちた1件だけは、なかったことになる。古い `field-observations.json` と `座標簿.json` は、SQLite が空のとき一度だけ取り込む。

## 落ちたあと

起動すると、直前のタブ、開いていたプロジェクト、作業、基準点の FIX の開始時刻に戻る。FIX の秒数は、その開始時刻から続けて数える。切れてやり直す印も残す。点そのものにしていない計測は、点の行にはしない。

画面に出す観測は新しい 80 点まで。残りは端末に置いたまま、起動では展開しない。

## GNSS

Bluetooth の GNSS は、一度選んだ機器を覚える。アプリが前面にあるあいだ、切れたら 2 秒あとに、画面のスレッドを止めずにつなぎ直す。前面を離れたら、つなぎ直しは止める。背面の通信モードは足さない。実機の切断と再接続は未確認。

## 測り方

`StabilityTests` が、コミット済みの点と途中の FIX が開き直したあとも残ること、コミット前の行が消えること、座標簿が WAL であること、2 万点を開いても表示は 80 点で増分メモリが 64MB を超えないこと、切断の呼び出しが待たずに戻り、そのあとつなぎ直すことを見る。
