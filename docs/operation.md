# 操作

初心者は直感で、慣れたら速く。既定は初心者。測るタブの「初心者」「慣れたら」で切り替わり、端末に残る。

## 初心者

ラベルの付いた大きなボタンだけを先に出す。点名の頭、次の点名、そして「現在地を残す」。押すと、残す前に点名と作業を見せる。「この点を確定」で残し、「やめる」で残さない。残ったあとは「次の点へ」。基準点は「基準点を開く」のあと。説明と GNSS は「くわしく」を開くまで出さない。

## 慣れたら

同じボタンを一回押すと、確認なしで残る。点名は次に進んだまま、続けて取れる。

- 残すボタンの長押し、または横スワイプで、すぐ観測して次の点へ。
- 音量ボタンと、アクションボタンの「観測を確定」。画面を見ずに残す。オフにもできる。
- 「もう一度」は、直前に成功した観測、基準点、作業の切替、書き出しをもう一回やる。
- 「よく使う機能の順番」で、残す、もう一度、基準点、作業、出すを並べ替える。項目は消えない。
- iPad のキーボード。⌘Return で残す、⌘R でもう一度、⌘B で基準点、⌘E で出す、⌘N で次の点、⌘Y で作業を変える。

音量とアクションボタンは、初心者には効かない。

## 手数

主要操作は 3 タップ以内。観測の確定は初心者 2、慣れたら 1。次の点まで含めると初心者 3。音量とアクションボタンは画面をタップしない。書き出しは、画面を開いて形式を選ぶので 2。

## 確定の返し

点を残せたときだけ、強い振動と、システムの短い音を返す。失敗したときは出さない。マナーモードでの音、音量ボタン、アクションボタン、キーボードは実機では未確認。

地図のピンチ、パン、回転と、シートのスワイプで戻るは、そのまま残す。
