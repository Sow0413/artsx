# AR位置出し

目標の点に、高さ 1.5m の仮想の杖を地面へ立てる。ラベルは点名と、歩数か距離（「右 16歩」）。次の点は同じ地面に、細く薄く出す。精度の段階バッジは、この画面でも常に出す。屋外の白地と原色に従う。

合わせは3つ。

1. 推奨。座標簿の既知点を2点以上、画面の地面でタップする。ARの水平を平面直角の東・北へ、縮尺1で写す。点ごとの残差と平均を出す。
2. 簡易。GNSSの位置と、2m以上歩いた軌跡の方位で向きを仮に置く。
3. RTK FIXのあいだは、向きを保ったまま、カメラの位置をGNSSへ足し続ける。

杖の根元は、LiDARのメッシュ、無ければ検出した水平面、どちらも無ければ高さ0に置く。映像は保存しない。視覚慣性のセッションは、相対高や歩測と一つを分け合う。

ずれの見積もりは、合わせからの時間に秒あたり 5mm、歩いた距離にメートルあたり 1cm を足し、既知点の残差と二乗和にする。10cm を超えたら再合わせを促す。この割合は設計値で、実機では未確認。

目標まで切替距離以上は、杖と歩数で案内する。既定は 1m で、それ未満になると杖を消し、前後左右のセンチとゲージに切り替える。切り替わったときは振動と音を一度出す。境界で行き来しないよう、数値のあいだは切替距離の 1.2 倍（既定 1.2m）以上で AR に戻す。切替距離は 0.2m から 20m で変えられ、端末の中だけに残す。以前の「最後の数cm」はこの距離に置き換えた。

声は画面の上を前にする。遠いときは「前です」「右前です」。切替距離未満は「もう少し前」。5cm以内は「そこです」。数字は画面だけに出し、方向が変わったときだけ話す。設定で数値も読める。重機のオペ画面の向きは変えない。

実機の ARKit、LiDAR、読み上げは未確認。
