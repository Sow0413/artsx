# クロスヘア水準器

背面カメラの画面に十字線を載せる。映像は保存しない。実機のカメラ、LiDAR、ARKit、振動は未確認。

水平モード。端末が鉛直で、仰角が ±0.1° のときを水平とする。入ったときに一度振動する。十字線は目の高さの水平線。スタッフの読み値を手で入れる。

- 器械高 = 自分の地盤高 + 目の高さ。
- 高低差 = 目の高さ − 読み値。読み値が目の高さなら 0。
- 相手の地盤高 = 器械高 − 読み値。

ターゲットモード。傾けて狙う。距離 D は LiDAR、無ければ ARKit、それも無ければ手入力。仰角 α は、鉛直からの後傾で、反転法のゼロ点を引いた値。

- 高低差 = D·sinα。
- 水平距離 = D·cosα。
- 方位と水平距離から、狙った点の緯度経度を出す。座標簿へ登録できる。種別は「簡易ターゲット」。

傾斜のゼロ点は反転法。同じ傾きのまま端末を 180° 回し、二回の平均を引く。

推定誤差は、距離の誤差と角度の誤差から出す。校正前の角度は 1.0°、校正後は 0.1°。水平で 20m、校正後なら「20mで ±3.5cm」。LiDAR は 5m まで 1cm。それより遠い LiDAR と、ARKit、手入力は距離が伸びると誤差も増える。

登録する点の段階は 0、受信機は iPhone、解は単独。バッジも段階0。端末の GNSS 精度より良い精度にはしない。測設の合格にはしない。
