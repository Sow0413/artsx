# 丁張

対象の高さに対して、今の測定高との差を画面中央の縦ゲージで出す。測量本体で、おまけのスイッチには依存しない。

目標は、図面の計画高にオフセットと勾配を足した値。オフセット +0.50m は、計画高より 50cm 上に貫を打つ。勾配は 1m あたりの高低で、向き（北から時計回り）が無いときは足さない。向きがあるときは、測設点から今の位置へ、その方位に沿った距離をかける。

測定高は二つから選ぶ。

- ポール先端。受信機の楕円体高からポール高を引く。ポール高が無ければ出さない。身長補正とは別の値で、身長の計算は変えない。
- 十字線の水平線。水平（±0.1°）のときだけ。器械高は地盤高 + 目の高さ。水平でなければ「高さになりません」と出す。

差が正なら高すぎるので下げ（赤、↓）。負なら上げ（青、↑）。絶対値が許容以内なら緑。許容は設定で、既定は ±5mm。作業一覧の「丁張・測設」の高低 1cm とは別。

大きな文字は「あと12cm下げ」。同じ文を読み上げる。残差が小さいほど間隔が短く、0 で 0.45 秒、1m 以上で 4 秒。実機の声とマナーモードは未確認。

平面の誘導は、測設点があるとき「現在地から距離、北から時計回り方位」をゲージと同時に出す。点が無ければ高さだけ。

残すと観測になり、種別は「丁張」。高さは決めた測定高で、身長補正は掛けない。精度の段階とバッジは常時出す。iPhone 単体は「目安」と書き、段階0、測設の合格にはしない。外部受信機なら、その段階を出し、目安とは書かない。
