# 61-2 精度管理の設計差分

門、帳票の文、器械設定、ジオイド格子の読み口はコードに入れた。紙の様式そのものとローカライズの計算はまだ無い。2セット較差は入れていない。

今の記録の流れは変えません。準拠モードのオンとオフのどちらでも、点は仮置き、人が検品、台帳へ、です。自動では台帳に入れません。

## 準拠モードは切り替えられる

司令メモ 73 のとおり、準拠モードはアプリに焼き込まない。現場ごとにオンとオフを切り替えられるようにする。既定はオフで、今の測り方のまま残す。オンにした現場だけ、下の門を掛ける。オフに戻した現場は、門を外す。記録の置き場所は同じです。

## オンのとき

- 解は FIX だけ。FLOAT、DGPS、単独は仮置きできない。
- 観測は 10 秒以上。足りないうちは仮置きできない。
- 帳票は、監督・検査要領（令和7年3月）の精度確認試験報告書。
- 許容は平面 ±20 mm、鉛直 ±30 mm。
- 2 セットの較差は使わない。要領のこの版には、その欄を置かない。
- 高さは公式ジオイド。現場パックのジオイド2024格子から、楕円体高を標高にする。受信機のジオイド高や、楕円体高から標高を引いただけの差では、合否を出さない。
- ローカライズの既定は、既知点 3 点以上。2 点では始めない。

## 今との差

| 項目 | 今 | 準拠モードをオンにしたあと |
| --- | --- | --- |
| 解 | どの解でも仮置きできる | FIX だけ |
| 時間 | 秒数の門は無い | 10 秒以上 |
| 帳票 | 精度確認試験報告書は無い | 要領（令和7年3月）の様式 |
| 許容 | 作業ごとの目安 | 平面 ±20 mm、鉛直 ±30 mm |
| 2 セット較差 | 無い | 入れない |
| 高さ | ジオイドを含む差は精度判定に使っていない | 現場パックのジオイド2024で標高にしてから判定 |
| ローカライズ | 出すタブの入口のみ。計算は次の版 | 既知点 3 点以上を既定 |
| 台帳 | 仮置きのあと、人が入れる | 同じ。自動では入れない |

オフの現場は、左の列のままです。鉛直が分かっていて 0.5° を超えるときは、準拠モードのオンオフに関係なく観測を始めません。傾きが無いときは止めません。

## 器械

カメラ位置と、アンテナから地面までの高さは別です。地面の高さは、楕円体高からアンテナ高を引いた値です。ポール高か、下レーザー（筐体 0.1877 m に測った距離を足す）かを記録に残します。

現場高さ補正（KBM 1点）は N = h − H です。時間を空けた 2 回の差が 2 cm 以内のときだけ採用します。KBM 自体は点検点にしません。H の出典、版、日付は必須です。

SPC+ の iPhone 15 Pro Max は X 0.022、Y 0.056、Z 0.017 m です。古い SPC と iPhone 17 Pro / Pro Max の公式値は未公開なので、測った値を Custom に残します。hw.machine の iPhone17,1 は 16 Pro です。

ファームウェアは Ver_ の行から読み、器械画面と記録に出します。レーザー cmd22 のバイト列が無いので、機能フラグはオフのまま送りません。mode 7 と認証の書き換えは送りません。
