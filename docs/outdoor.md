# 屋外の見え方

既存機の液晶は、日向だと文字が沈む。この画面は、外では白地に太い黒線と原色だけを使う。影も、半透明も使わない。

## 色

本文と補足は黒（補足は `#222`）を白地に置く。コントラストは WCAG AAA の本文 7:1。60pt のボタンと、18pt 以上または 14pt 太字は 4.5:1。

青 `#002D9C`、赤 `#9E0000`、緑 `#006400` は、白地にも、その色地に白文字を置いても足りる。黄 `#FFD600` は白地に置くと 1.4:1 しかないので、文字にはしない。黄地に黒文字の札だけに使う。図面の線で 7:1 を切る色は、太さ 3pt の黒線に替える。

夜の暗い画面はそのまま残す。屋外は、その上に被せる切替である。

## 切替

画面の明るさが 0.6 以上のとき、自動で屋外にする。下の「表示」ボタンで、自動、屋外、屋内を順に固定できる。選んだ位置は端末の `survey.outdoor` に残る。明るさの監視は前面にいるあいだだけで、実機での切替は未確認。

## 文字とボタン

文字は固定のポイントではなく、iOS の Dynamic Type（caption から largeTitle）に載せる。主要操作のボタンは高さ 60pt 以上で、手袋のまま押せる大きさにする。

## 操作

地図はピンチ、パン、回転。図面もピンチ、ドラッグ、回転。図面を長押しすると「全体を表示」と「回転を戻す」。測るタブの点を長押しすると、点名と座標をコピーする。出すで書いたファイルは、システムの共有シートで渡す。シートの戻りは NavigationStack のスワイプと閉じるボタン。戻るボタンは隠さない。新しいジェスチャーは足していない。共有シートの実機動作は未確認。
