# 優先順位

測量本体を先に完成させる。おまけは、そのあとで、今ある最小の実装のまま残す。

## 本体

座標簿、図面、測設、基準点、出力、実 SFC、重機のオペ画面。ここがこのアプリの仕事である。スイッチには依存しない。

本体の最優先は、大きい現場で固まらないこと。延長 1km 以上、座標簿 5 万点、SFC / DXF は 10MB 級。パンとズームは 60fps、起動から操作できるまで 2 秒、スナップと座標簿の絞り込みは 100ms、メインスレッドは止めない。詳細は `docs/performance.md`。

落ちても観測を失わないこと。変更はすぐ端末の SQLite（WAL）に書く。強制終了のあとは、直前の画面と、途中の基準点計測に戻る。GNSS の Bluetooth が切れても画面は止めず、前面にいるあいだはつなぎ直す。対象は iPhone / iPad だけ。詳細は `docs/stability.md`。

外で読めること。白地、太い黒線、原色。影と半透明は使わない。画面が明るいときは屋外表示に切り替え、ボタンでも固定できる。主要操作は 60pt。ピンチ、スワイプで戻る、長押し、共有シートは iOS の標準。詳細は `docs/outdoor.md`。

操作は、初心者は大きなボタンと確認、慣れたら少ない手数。主要操作は 3 タップ以内。長押し、スワイプ、音量ボタン、アクションボタン、キーボードは、慣れてからの近道。詳細は `docs/operation.md`。

段階0の iPhone は、初回に身長だけ聞けば使える。既定の持ち方は肘より上（身長×0.70）。係数は設定で変えられ、既知の高さで1回校正もできる。外部 GNSS のポール高とは別。詳細は `docs/stature.md`。

## おまけ

次はおまけである。設定で一つずつオン、オフできる。既定は全部オフで、そのあいだは測量の画面にボタンも帯も警報も出さない。中継も、位置の送信も、加速度も、押して話すも始めない。

| スイッチ | オンにしたときだけ |
| --- | --- |
| 押して話す | オペ画面の無線と、話しているあいだの矢印 |
| 接近警報 | 相手の位置、ヒヤリ、音、画面の色 |
| 転倒 | 加速度での転倒と衝撃 |
| SOS | スライドの SOS。119 は自動で掛けない |
| 初動 | SOS か転倒のあと、最寄りと 119 の読み上げ |
| 事故報告 | 確定した記録からの対外説明 PDF |
| 災害 | 被災箇所と通行。位置の共有も、これか接近がオンのときだけ |
| メッシュ | 見通し範囲の中継。オフのあいだは中継しない |
| 統計 | この現場の件数とヒートマップ |

入口は、地図と「出す」の「おまけ」。状態は端末の `おまけ.json`。プロジェクトの記録にはしない。

積んである仕様は、実装を広げずに設計書へ残す。

- 無線 `docs/ptt.md`
- 災害 `docs/disaster.md`
- メッシュ `docs/mesh.md`
- 位置の共有 `docs/privacy.md`

接近、転倒、SOS、初動、事故報告、統計の動きは README の「おまけ」に書いてある。ここから先の実装は、本体が一段落してから、必要なものだけ最小の版で足す。
