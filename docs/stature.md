# 身長補正

段階0、つまり iPhone 単体のときだけ使う。端末が出す楕円体高から、持ち高さを引いて地盤高にする。外部 GNSS のポール高とは別の値で、ポール高を変えてもこの補正は動かない。

初回起動で身長が無ければ、身長だけを聞く。保存すれば、既定の持ち方で使える。閉じても測量は止まらない。次に起動したとき、まだ身長が無ければもう一度聞く。

持ち方は次の七つ。一覧の先頭が既定。

- 画面の角度。既定。目の高さは身長 − 0.10m。端末が鉛直で視線が水平のとき、端末の中心は目の高さ。これが基準で、鉛直から ±1° 以内の観測は「目線水平」と記録し、d·sinθ は掛けない。画面の水平器（気泡管）が中央に来ると、一度振動する。それ以外の角度は、端末高 = 目の高さ − d·sinθ。下がりもこの基準で、目線水平は 0、傾いていれば d·sinθ。θ は鉛直からの後傾で、CoreMotion の pitch から出す（pitch 0 は画面を上に向けて水平、+π/2 は端末の上が真上）。d は TrueDepth / ARKit の顔追跡で、カメラから顔までの距離。顔が無い、15cm 未満、1m 超のときは 35cm。観測を確定した瞬間の θ と d を使う。
- 肘より上。身長 × 0.70。画面の角度の代わり。
- 胸の前。身長 × 0.72。
- 目の高さ。身長 − 0.10m。傾きは使わない。
- 地面に置く。0。
- 重機運転席。既定 2m。オペ画面の視線高と同じ出発点で、こちらを変えても視線高は動かない。
- 手入力。

GNSS アンテナは端末の中心にない。機種ごとの定数は、公表の本体高さの半分から上端 15mm を引いた、portrait 上方向の距離。傾けると鉛直成分は定数 × cosθ。表に無い機種は 0.060m。実機のアンテナ位置は未確認。顔までの距離も、画面中心までの距離ではない。実機の TrueDepth と CoreMotion は未確認。

画面の角度のときだけ、前面で傾きと顔追跡を始める。映像は保存しない。顔追跡ができない端末は 35cm のまま。肘より上に切り替えると、顔追跡は止める。

肘より上の係数、胸の係数、目の高さから引く長さ、運転席の高さは設定で変えられる。画面の角度、肘より上、胸の前、目の高さは、身長が無いと掛けない。傾きがまだ無い画面の角度は掛けない。

既知の楕円体高の点で1回観測すると、端末高との差をその人の持ち高さにし、代わりの肘より上の係数を合わせる。既知高さも端末と同じ楕円体高。校正した日、既知高さ、持ち高さ、係数を端末に残す。

身長を一度入れると、同じ値で歩幅の初期値も置く。歩幅は身長×0.45。0.3m 未満か 1.5m 超になるときは歩幅だけ入れない。既知距離を歩いて歩幅を合わせると、そちらに替わり、そのあとに身長を変えても歩幅は書き直さない。持ち高さの校正と歩幅の校正は、同じ「自分の校正」に出す。校正した日と値は、この端末の UserDefaults（`survey.stature` と `survey.pace`）だけに残す。プロジェクト、座標の共有、接近警報には出さない。点に残る身長補正は、その点の持ち高さであり、このプロフィールそのものではない。

点を残すとき、端末の楕円体高はそのまま残す。GNSS の条件記録に、持ち方、引いた量、そのときの身長と係数、地盤高を書く。画面の角度では θ、d、アンテナ差も書く。座標簿に出す高さは地盤高。あとから身長や係数を変えたら、「取った点を、今の身長でやり直す」で段階0の点だけ掛け直せる。画面の角度の点は、その点を取った瞬間の θ と d とアンテナ差を残して、目の高さだけ掛け直す。角度を記録していない点は、画面の角度には掛け直さない。

身長 1.70m、後傾 30°、距離 0.35m、アンテナ差 0.06m なら、画面には「身長補正 −1.48m」と「下がり 0.18m」と出す。鉛直から 1° 以内なら「目線水平」で、端末の中心は目の高さ、下がりは 0.00m。GNSS はアンテナの高さなので、その機種の定数は別に引く。段階0でないとき、または iPhone 以外の受信機のときは出さない。オペ画面で端末を目の高さで持つときも、同じ基準で下がりを出す。実機の振動は未確認。
