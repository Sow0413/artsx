# 身長補正

段階0、つまり iPhone 単体のときだけ使う。端末が出す楕円体高から、持ち高さを引いて地盤高にする。外部 GNSS のポール高とは別の値で、ポール高を変えてもこの補正は動かない。

初回起動で身長が無ければ、身長だけを聞く。保存すれば、既定の持ち方で使える。閉じても測量は止まらない。次に起動したとき、まだ身長が無ければもう一度聞く。

持ち方は次の六つ。一覧の先頭が既定。

- 肘より上。身長 × 0.70。既定。
- 胸の前。身長 × 0.72。
- 目の高さ。身長 − 0.10m。
- 地面に置く。0。
- 重機運転席。既定 2m。オペ画面の視線高と同じ出発点で、こちらを変えても視線高は動かない。
- 手入力。

肘より上の係数、胸の係数、目の高さから引く長さ、運転席の高さは設定で変えられる。肘より上、胸の前、目の高さは、身長が無いと掛けない。

既知の楕円体高の点で1回観測すると、端末高との差をその人の持ち高さにし、肘より上の係数を合わせる。既知高さも端末と同じ楕円体高。

点を残すとき、端末の楕円体高はそのまま残す。GNSS の条件記録に、持ち方、引いた量、そのときの身長と係数、地盤高を書く。座標簿に出す高さは地盤高。あとから身長や係数を変えたら、「取った点を、今の身長でやり直す」で段階0の点だけ掛け直せる。

身長 1.70m で既定のままなら、画面には「身長補正 −1.19m」と出す。段階0でないとき、または iPhone 以外の受信機のときは出さない。
